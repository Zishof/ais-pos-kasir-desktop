⚙️ Pengaturan Alamat Server

Isi sekali di awal supaya aplikasi tahu ke server AIS mana harus terhubung. Bisa diubah kembali kapan saja lewat menu Pengaturan → Ubah Alamat Server.

Alamat domain/server AIS Anda, TANPA "https://" dan tanpa garis miring di akhir. Tanyakan ke admin sistem/IT institusi Anda bila belum tahu.
Bagian path setelah domain (bila ada) -- mis. jika alamat lengkapnya "demo.ecampus.id/ecampus", isi "ecampus" di sini. Kosongkan bila server Anda langsung di root domain.
Biarkan tercentang kecuali admin sistem Anda secara eksplisit mengarahkan memakai HTTP biasa (mis. server internal tanpa sertifikat SSL). Koneksi tanpa HTTPS tidak terenkripsi.
