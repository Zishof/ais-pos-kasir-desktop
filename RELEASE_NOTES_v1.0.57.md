# AIS POS Kasir Desktop v1.0.57

## Perbaikan

1. Hak akses menu POS Desktop sekarang mengikuti flag menu Kantin dari grup pengguna.
2. Akun multi-toko dari grup pengguna menampilkan pilihan toko aktif, dan semua request POS otomatis memakai toko yang dipilih.
3. Pilihan toko aktif disimpan ke server supaya konsisten saat membuka menu kasir, ringkasan, pesanan, produk, stok, laporan, dan konfigurasi.

## Catatan

- Perlu server AIS versi terbaru yang sudah memiliki aksi POS `pilih_toko_aktif`.
